# Module Icon

This directory should contain a 48x48 pixel GIF icon named `icon.gif`.

The icon will be displayed in the Webmin interface when users access the Brightspeed Postfix Relay module.

## Requirements
- Format: GIF
- Size: 48x48 pixels
- Name: icon.gif
- Color scheme: Should match Webmin's color palette (blues and grays typically work well)

You can create this icon using any image editor and place it here as `icon.gif`.
